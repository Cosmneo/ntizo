# Single Web App Consolidation — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the three Ntizo frontend apps (landing, admin, provider) with one React app `apps/frontend/web` that serves a public landing at `/`, a provider zone at `/provider/*`, and an admin zone at `/admin/*`, with an in-app zone switcher.

**Architecture:** A single Vite + React 19 SPA using TanStack Router file-based routing, scaffolded from the `doazores-web-provider-react` reference. Path-based zones with per-zone layout guards (`beforeLoad`). Data layer is Ntizo's existing REST + better-auth (no GraphQL). Roles come from `GET /api/me` (`CurrentUserDTO.role`) and provider membership from `GET /api/providers/mine`. Deployed as one Cloudflare Worker serving the SPA at the site root.

**Tech Stack:** Vite, React 19, TanStack Router (file-based, autoCodeSplitting), TanStack Query, TanStack Form, Tailwind v4, better-auth (`better-auth/react`), i18next + react-i18next (en/pt), lucide-react, Vitest + Testing Library, Cloudflare Workers (wrangler). Reuses workspace packages `@ntizo/frontend-ui` and `@ntizo/shared`.

## Global Constraints

- Node `>=18`; package manager `bun@1.3.9`; TypeScript `5.9.2` (pin, matches monorepo).
- App workspace name: `@ntizo/web`. Location: `apps/frontend/web`. Dev port: **3000**.
- Import alias: `@ → ./src` (via `vite.config.ts` resolve.alias AND `tsconfig.json` paths).
- Router `basepath: "/"`. Vite `base: "/"`.
- Data layer: **REST + better-auth only. Do NOT add GraphQL / `@cosmneo/onion-lasagna-*` deps.**
- Backend origin in dev via Vite proxy: `/api → http://localhost:8788` (env `DEV_WORKER_ORIGIN` overridable). better-auth `baseURL` is `""` in dev (same-origin through the proxy), `VITE_AUTH_API_URL` in deployed builds.
- i18n languages: `en`, `pt` (fallback `en`).
- `UserRole = "customer" | "individual_provider" | "organization_owner" | "admin"`.
- Zone rules: landing is public; `/provider/*` requires a session (non-providers land on `/provider/no-provider`); `/admin/*` requires `role === "admin"`.
- Do NOT touch: `apps/backend/*`, `packages/*` (except importing), `apps/mobile`, and the repo-root `landing/` and `landing 2/` folders.
- Work happens on branch `feat/single-web-app-consolidation` (already created). Commit after every task.
- Deletion of the three old apps happens ONLY in Task 11, behind an explicit confirmation gate.

- [ ] **Step 3: Implement `src/shared/lib/env.ts`**

```ts
const ENV_DEFAULTS = {
  VITE_AUTH_API_URL: "http://localhost:8788",
} as const;

type EnvVar = keyof typeof ENV_DEFAULTS;

function readEnv(key: EnvVar): string {
  const value = import.meta.env[key];
  return value && value.length > 0 ? value : ENV_DEFAULTS[key];
}

/** better-auth backend origin (used only in deployed builds; dev proxies /api). */
export const AUTH_API_URL: string = readEnv("VITE_AUTH_API_URL");

const requiredEnvVars: EnvVar[] = ["VITE_AUTH_API_URL"];

/** Throw if a required env var is missing in a deployed (non-dev) build. */
export function validateEnv(): void {
  if (import.meta.env.DEV) return;
  const missing = requiredEnvVars.filter((key) => {
    const value = import.meta.env[key];
    return !value || value.length === 0;
  });
  if (missing.length > 0) {
    throw new Error(`Missing required environment variables:\n${missing.join("\n")}`);
  }
}
```

```ts
import type { CurrentUserDTO } from "@ntizo/shared";

export type Zone = "landing" | "provider" | "admin";

const PROVIDER_ROLES: ReadonlySet<CurrentUserDTO["role"]> = new Set([
  "individual_provider",
  "organization_owner",
]);

export function canAccessAdmin(user: CurrentUserDTO | null): boolean {
  return user?.role === "admin";
}

export function canAccessProvider(
  user: CurrentUserDTO | null,
  providerCount: number,
): boolean {
  if (!user) return false;
  return providerCount > 0 || PROVIDER_ROLES.has(user.role);
}

export function accessibleZones(
  user: CurrentUserDTO | null,
  providerCount: number,
): Zone[] {
  const zones: Zone[] = ["landing"];
  if (canAccessProvider(user, providerCount)) zones.push("provider");
  if (canAccessAdmin(user)) zones.push("admin");
  return zones;
}

/** True only for app-internal absolute paths ("/x"), never external URLs. */
export function isSafeInternalPath(path: string | null): boolean {
  if (!path) return false;
  return path.startsWith("/") && !path.startsWith("//");
}

export function resolvePostLoginDestination(
  user: CurrentUserDTO | null,
  next: string | null,
): string {
  if (isSafeInternalPath(next)) return next as string;
  if (canAccessAdmin(user)) return "/admin";
  if (user && PROVIDER_ROLES.has(user.role)) return "/provider";
  return "/";
}
```

```ts
import type { CurrentUserDTO } from "@ntizo/shared";
import { canAccessAdmin } from "@/shared/lib/zones";

type MaybeSession = { user?: unknown } | null | undefined;

export function resolveAdminGuard(
  session: MaybeSession,
  me: CurrentUserDTO | null,
  path: string,
):
  | { redirectTo: "/sign-in"; search: { next: string } }
  | { redirectTo: "/" }
  | null {
  if (!session || !session.user) return { redirectTo: "/sign-in", search: { next: path } };
  if (!canAccessAdmin(me)) return { redirectTo: "/" };
  return null;
}
```

```tsx
import { useQuery } from "@tanstack/react-query";

        >

        </Link>
      ))}
    </nav>
  );
}

export function ZoneSwitcher({ current }: { current: Zone }) {

  const zones = accessibleZones(me, providers.length);
```

- [ ] **Step 1: Create `worker/index.ts` (root-basepath SPA fallback)**

```ts
interface Env {
  ASSETS: { fetch: (input: Request | URL | string) => Promise<Response> };
}

export default {
  async fetch(request: Request, env: Env): Promise<Response> {
    const url = new URL(request.url);
    // Try a static asset first; if present, serve it as-is.
    const asset = await env.ASSETS.fetch(request);
    if (asset.status !== 404) return asset;
    // SPA fallback: serve index.html for deep client routes.
    const shell = await env.ASSETS.fetch(new URL("/index.html", url.origin));
    return new Response(shell.body, {
      status: 200,
      headers: { "content-type": "text/html; charset=utf-8", "cache-control": "no-store" },
    });
  },
};
```
