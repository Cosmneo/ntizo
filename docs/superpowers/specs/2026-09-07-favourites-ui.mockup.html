The problem

A tile that was designed to have no buttons now needs one

The listings refresh removed every control from a result. Its own note says it plainly: “There is no second control on the tile.” The price carries the eye, the tile is the link, and the page spends its single blue exactly once, on the search button. Adding a heart means adding back the thing that design deliberately took away, so it has to cost as little as possible.

Three rules came out of that. The heart lives on the photograph, never in the three lines of text, so the words keep their column and the grid keeps its rhythm. It is the only control on a result, so it never has to compete. And it borrows the language the design already uses for “this one is chosen” — the filled navy of an active filter pill, the current page number, the verified seal — rather than introducing a colour that appears nowhere else.

On the photograph, top-right. The three text lines keep their column, so a saved tile and an unsaved one are exactly the same height and the grid never shifts.

A white disc, not a bare icon. The photographs are somebody else's and can be any colour; a stroke-only heart disappears on a pale one. The disc is the smallest chrome that survives every photo, and it is the only chrome on the tile.

The empty-photo tile keeps it. The heart sits on the brand fallback exactly as it sits on a photograph, so the control does not move depending on whether a business uploaded a picture.

The one open question

Which heart is a saved heart?

The 2026-08-27 spec chose a rose that deliberately left the palette. That spec was written against a blue-accented design where a blue heart would have read as a second call to action. This design is different, so the reasoning needs re-testing rather than inheriting.

Navy. The colour this design already uses for “chosen”.

Rose #e5397a. The web’s convention for a saved thing.

Recommended

Navy

In this design, filled navy already means chosen: the active filter pill, the current page number, the verified seal. A filled navy heart says “on” in a sentence the page is already speaking, and the palette stays at two colours plus the amber star. The risk is that it is quieter than a red heart, and a person scanning fast may not register the state as instantly.

Rose

Unmistakable, and every other site on the web has taught it. The cost is a third hue that appears on nothing else — not a filter, not a badge, not a link — so it reads as imported rather than designed, and it competes with the navy price directly beneath it, which is the one thing on the tile meant to catch the eye.

1440 · after the heart is pressed

The dialog files it; it never asks permission

Pressing the heart saves. This opens afterwards, already knowing the answer, and its only button is Done. That is why the green line says saved in the past tense and why there is no Cancel: there is nothing to cancel, and a Cancel would imply the save had not happened.
